# C 给 D/E 的交接包

主要三项：交接说明（08）、运行样例（examples/de_handoff_smoke.py）、安装包（release/*.whl）。
配套包含迁移文件、指标字典及接口缺口说明（09）。

先解压，在解压目录打开终端，使用 Python 3.11 或以上版本：

```bash
python -m pip install ./data_foundation/release/anhui_data_foundation-0.1.0-py3-none-any.whl
python data_foundation/examples/de_handoff_smoke.py
```

默认使用临时 SQLite 和合成数据，预期 status 为 passed、check_count 为 18。
详细操作及 MySQL 测试要求见 data_foundation/08-C到DE交接说明与实调样例.md。
当前仅验证最小存储流程，真实 MySQL 和 D/E 接收方验收仍待完成。
本包不含第三方依赖安装包，首次安装依赖通常需要联网。
