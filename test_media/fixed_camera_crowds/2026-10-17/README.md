## 视角核对与素材保持

每段均已抽取开头、中间、末尾三帧核对固定背景，并从头到尾解码检查。`previews/`有每段三时点对照图和总览；这次核对视角，不只检查文件能否播放。

视频直接保存官方提供的 `sequence / raw.mp4` 字节，没有再转码、剪辑、变速或插帧，也没有绘制检测框。它们是官网发布的未标框MP4版本，实际约540p；基准原始帧包的更高分辨率未下载，不将当前文件称作1080p原始帧。

部分视频左上角白色数字是来源自带帧号，底部RAW是来源标识，**不是人数或模型输出**。本批未附人数真值、未执行计数模型、未验收MAE或预测。录制绝对时间未知，只提供视频相对秒数，不写入业务录像或授权台账。

## 输入与自检

`test_inputs.json` 为这五段的相对路径输入；`manifest.json` 记录下载地址、摘要、时长、实际尺寸及视角核对。`*-download.json` 是原下载记录，`*-qa.json` 是解码/抽帧记录。

```bash
python verify_media.py
```

ZIP包含五段MP4、总览、三时点预览、清单、自检脚本及说明。没有修改爬虫、C/D/E业务代码或正式数据库。
