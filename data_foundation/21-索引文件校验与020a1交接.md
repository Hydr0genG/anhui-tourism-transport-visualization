# C 0.2.0a1：单文件索引产物校验

交付日期：2026-10-14。预发布包0.2.0a1，迁移0006、31表不变。稳定交付0.1.9及其原件快照保留。本版推进[0.2.0计划](./20-v020启动计划.md)的G10通用文件保护，尚未关闭完整G10：E向量格式、文件/文档版本/片段内容对应关系，以及真实Worker/HTTP/问答仍待接收；G18预测验证未在本版实现。

## 已实现接口

```python
uow.knowledge.activate_index(
    *, document_id: str, version: str, artifact_path: str,
    artifact_sha256: str, expected_chunk_count: int, lease: JobLease,
    expected_artifact_byte_size: int | None = None,
) -> dict[str, Any]

uow.knowledge.get_index_artifact_ref(
    document_id: str, version: str | None = None,
) -> dict[str, Any]
```

activate_index保持此前参数及返回形状，新增可选预期大小。**所有成功发布都要求真实文件与DATA_ROOT**，旧的虚构路径不再接受。已有0.1.9活动索引记录未删除或改写，但新读取入口也会检查其真实文件；历史记录若只保存占位路径，必须重建真实产物，不能绕过检查。

artifact_path须为最多500字符、规范的POSIX相对路径，拒绝绝对路径、`..`、反斜杠、NUL、盘符、重复斜杠及所有符号链接（包括指向根内的链接）。目录/FIFO/设备不是可发布产物。摘要须为64位小写SHA256；expected_artifact_byte_size如提供，须为非负int，拒绝bool/float/字符串。文件不存在为NotFound，非法参数/文件类型为InvalidArgument，摘要/大小不符或检查期间变化为Conflict；既有LeaseLost及任务归属保护保留。

本版接受普通单文件的任意字节，不反序列化向量、模型或归档，不把“摘要正确”解释为“模型/文档内容正确”。空文件没有额外语义判断；expected_chunk_count仍与数据库片段数核对，不证明片段与向量对应。多文件目录、容器格式及内容清单待E样例确认，不通过把目录哈希成字符串冒充支持。

## 发布、租约与文件竞争

方法先做非加锁租约及索引归属检查，并流式读取文件计算SHA256/大小；读取前后检查文件inode、device、size、mtime/ctime纳秒值。随后按现有Job→JobAttempt→Document→Index锁顺序刷新当前状态，核对片段数量，检查文件元数据仍一致，最终再次检查实时时钟租约，再修改索引和活动版本。

正常使用时，不在计算摘要前新增Job/Attempt发布锁。**如果调用方已经在同一事务执行begin_index/write_chunks或其他加锁操作，原有锁会保持到事务结束**；D/E应先构建/落盘、分批写片段并结束这些事务，再用短事务activate_index+complete_job。不得把解析、embedding或等待外部服务放在发布事务中。

示例使用store.persist_file在事务外按内容寻址落盘；文件应交给受管理目录，发布后不改写。锁后复核是文件元数据检查，不能防止任意外部进程在最后检查之后改写文件，也不能保证文件系统与数据库原子提交。调用方长时间延迟commit仍可能跨越租约期限；没有提交瞬间的自动租约复验承诺。不宣称高并发吞吐已验收。

激活和任务完成必须放在同一store.write，异常传播出上下文以触发整体回滚。若调用方自行捕获异常后继续提交，就不能获得这一整体回滚保证。本版未强制两方法合并，也不删除已提交业务记录或孤立文件。

## 调用与读取

```python
# 构建/落盘在事务外。stream是E产物文件流；不读取不受信文件格式。
artifact = store.persist_file(
    source_id=source_id, original_name="index.bin", stream=stream,
)
with store.write() as uow:
    uow.knowledge.activate_index(
        document_id=document_id, version=index_version,
        artifact_path=artifact["relative_path"], artifact_sha256=artifact["sha256"],
        expected_artifact_byte_size=artifact["byte_size"],
        expected_chunk_count=chunk_count, lease=lease,
    )
    uow.jobs.complete_job(lease, {"document_id": document_id,
        "index_version": index_version}, now)

with store.read() as uow:
    internal = uow.knowledge.get_index_artifact_ref(document_id)
```

新增读取未就绪时返回`{"status": "index_not_ready"}`；文档不存在为NotFound。默认使用活动版本，也支持指定已ready版本。成功返回status/document_id/index_id/version/parser_version/embedding_model_version/relative_path/sha256/byte_size；byte_size为本次实读大小，可选预期大小不新增持久字段。读取重新计算摘要，文件缺失/损坏则报错，不静默返回可加载引用，也不自动撤销已提交索引。

这是D/E内部加载引用，**不直接作为HTTP响应**。D继续过滤相对文件路径、令牌和内部材料；E只在受管理根目录加载，读取引用后文件仍可能变化，需管理不可变产物与加载时完整性。既有get_chunks返回形状不变，且仅访问数据库片段；它不会自动读取/验证文件，E加载器须接新入口。
