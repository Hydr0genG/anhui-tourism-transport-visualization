# 0.1.4：任务领取筛选与 D/E 交接

交付日期：2026-10-13。C 包版本 0.1.4，迁移 head 0005，指标字典仍为 0.1.0。本步完成 G08 的类型/ID 领取筛选；进度更新、过期恢复和失败重试仍待实现。D 仍负责统一领取与分发，E 通过 D 获得处理入口和租约。本次没有操作业务库或 D/E 仓库。

## 实际接口

```python
def claim_job(self, worker_id: str, now: datetime, lease_seconds: int = 120, *,
              job_type: str | None = None, job_id: str | None = None) -> dict | None:
```

筛选精确匹配、区分大小写和尾部空格，同时提供类型和 ID 时必须都匹配。None 表示不筛选；非字符串、空串或纯空白会抛 InvalidArgument。不存在的类型/ID、条件冲突、未到执行时间、任务已运行或已结束均返回 None，不回退领取别的任务。job_id 是 jobs.id，不是 document_id、video_id 或 analysis_id。

只领取 queued 且 available_at <= now 的任务。无筛选时继续按 created_at、id 排序，原三个位置参数和返回结构保持兼容。筛选在同一条 FOR UPDATE SKIP LOCKED 查询中完成；成功领取仍写入 running 状态、增加 attempt_count、登记租约尝试，调用方的写事务提交后才生效。回滚会同时撤销任务变化和尝试记录。

## 安装与复验

从交接包中的 data_foundation 目录执行：

```bash
python -m pip install release/anhui_data_foundation-0.1.4-py3-none-any.whl
PYTHONPATH=. python -m pytest
PYTHONPATH=. python examples/de_handoff_smoke.py --target local --part all --report /path/to/test-report.json
```

Windows PowerShell 可先设置 `$env:PYTHONPATH="."`，再执行不带 PYTHONPATH 前缀的 Python 命令。安装包本身不含迁移、外部样例或真实资料，使用配套 ZIP。已在 0005 的数据库无需新增结构迁移。

MySQL 领取验收脚本仅允许 TEST_DATABASE_URL 指向名称以 `_test` 结尾、无表的独占测试库，脚本会迁移，不能对业务库执行。配置测试环境后运行：

```bash
python examples/verify_job_claim_filters.py --report /path/to/mysql-claims.json
```

脚本用两个不同连接的重叠事务验证：同一任务只领取一次；被锁定的指定 ID 不回退到其他任务；回滚后可重新领取且旧租约无效；类型查询可跳过显式主键锁定的行；组合条件和大小写/尾部空格不匹配时无副作用。
