## 3. 三个容易误解的地方

### 3.1 “实调完成”与“统一正式库”是两个验收点

D 已经把 HTTP 路由接到了 E 的函数，但给 Worker 的是 D 自己的 d_ 前缀 SQLite 桥接存储。可以证明 D/E 调用链在该环境跑通，不能证明正式 MySQL、C 实际仓储方法和全部业务读取已接完。D 回执明确保留 H01 切换任务，C 无需替 D 重写后端。

### 3.2 Worker 的分工可以统一

“D 是唯一 Worker 进程”与“使用 E 的 AnalysisWorker 类”可以同时成立：D 启动一个进程并注入 store，E 的类在进程内运行算法与存储适配。联调时记录实际领取者和心跳/失败调用者，避免额外启动第二个领取进程。D 的 save_knowledge_index 桥接路径还应核对与 C activate_index 的映射、完成发布是否仍在同一事务。

### 3.3 真实存储不等于真实资料

E 的“真实 C store 集成”表示使用了 C 的代码和仓储入口；其材料同时明确缺少真实素材。问答引用、视频计数误差和预测质量，仍需正式原件/授权视频/人工标注/历史计数验证。

## 4. C 下一步的执行顺序

### 第一步：收尾本次验收

- 归档 D 两份 21 项报告与回执，关闭 MySQL 微秒精度缺陷。
- 保留版本组合：C 包 0.1.1、迁移 0005、指标字典 0.1.0。
- E 收到新版后补 e 组 13 项结果；其 0.1.0 验收不重写成 0.1.1 验收。
- 完成判据：总表清楚区分已通过的存储与未完成的路由、真实资料。

关键词：验收回执、版本、迁移 head。

### 第二步：先交付一份真实知识文档

这条线与第三步接口实现可并行。先确认一个景区/站点/区域，固定实体 ID；取得适用的官方知识原件，核验来源与使用条件，再登记来源、原件和文档。

每份至少包含：原件文件、名称、发布单位、来源链接、发布日期、适用起止时间、使用/授权说明、对应实体 ID、原件摘要与定位信息。未知日期或条件明确标记待核验，不推定永久有效或可用。

交付后：E 解析/建立索引 → D 接正式查询 → 验证一个问题能引用正确片段和出处；资料不足时正确显示不足。项目完整判据仍要求至少两份官方资料，首份用于先打开真实链路。

分支：对象未定则先定一个试点；原件或条件未核实则继续核验并保留不足状态；一份先就绪则先交 E，不等待四类齐全。

关键词：知识文档、实体 ID、来源台账、原件、引用。

### 第三步：按 D 的 H04 优先级补 C 接口

1. get_document / list_documents：让上传后的文档能查询，支撑 21 号接口。
2. claim_job 类型或 ID 过滤：减少混合队列实调中的领取歧义；现有 FIFO 行为不是缺陷。
3. 视频详情、列表、受授权约束的回放引用：支撑录像页面；拿到引用不等于允许回放。
4. list_events 的 kind/entity_id/authority/since/until 筛选。

知识/分析失败状态、租约恢复/重试、人工标注和预测 run 读取仍在缺口清单；每次交付同步实际签名、版本和样例，不把旧设计中的方法默认视为已实现。

关键词：H04、文档详情、列表、作业筛选、回放授权、失败生命周期。

### 第四步：配合 D 切正式 store，并完成指标注入

D 负责认证桥接、六路由的正式存储适配、Worker 切 C jobs 和 metric_query。C 负责提供已实现方法、真实指标范围、可用粒度、周期和缺期说明。E 按相同存储契约验证算法调用。

联合验证：同一真实文档从入队到索引发布、文档列表/详情再到带引用问答，均使用 C 正式库；metric_query 只接受实体/指标/粒度/日期结构化参数，使用五指标白名单，拒绝非法参数。C 的 query_series 使用 metric 字段，D 注入函数的 metric_code 需要显式转换，不能直接把注入参数原样透传。

关键词：H01、统一 store、JobLease、metric_query、白名单。

### 第五步：交付视频、人工标注和连续计数

| 素材 | 最小交付内容 | 用途 |
|---|---|---|
| 授权录像 | 文件、video_id、permission_id、景区/摄像头 ID、入口名称、录制起止、0—1 虚拟线坐标、进入方向、是否可回放 | 检测/跟踪/进出计数 |
| 人工标注 | 对应视频片段、窗口、进/出人数、版本、遮挡/中断/重复经过说明 | 比较算法计数和人工值，评价误差 |
| 连续历史计数 | 同一入口的连续窗口、entries/exits 分列、质量和来源、缺窗/中断说明 | 短时预测训练与回测 |

C 与 E 要用同一片段示意确认“左/右”相对虚拟线的意义，保存线与方向配置，不能仅凭一个方向词判断。没有录像授权时先推进知识与历史客流，录像保持待资料；没有足够连续窗口时正确返回 data_insufficient。

B 的 1/5/15 分钟展示需求还需核对实际接口：C 当前 query_counts 只接受 video_id/analysis_id，没有窗口/粒度聚合参数。由 D/E 明确聚合位置和规则后验收，不能把页面需求视为 C 已支持。

关键词：录像授权、虚拟线、进入方向、人工误差、连续窗口、数据不足。
